# 🧠 Python Quiz Application

A simple and interactive **Quiz Application** developed using **Python** and **Tkinter**. The application allows users to enter their name, answer multiple-choice Python programming questions, and view their final score.

---

## 📖 Overview

The Python Quiz Application is a GUI-based desktop application designed to test users' knowledge of Python programming. It provides an easy-to-use interface with multiple-choice questions and displays the final score after the quiz is completed.

---

## ✨ Features

- 👤 User login with name
- ❓ Multiple-choice quiz
- 📝 Five Python programming questions
- 🎯 Automatic score calculation
- 🖥️ User-friendly graphical interface
- 📊 Display final score
- ⚡ Simple and lightweight application

---

## 🛠️ Technologies Used

- Python 3.x
- Tkinter (GUI)
- Functions
- Event Handling


```bash
cd Python-Quiz-App
```

### Run the Application

```bash

```

## 📋 Quiz Flow

1. Enter your username.
2. Click **ENTER**.
3. Answer five multiple-choice questions.
4. Your score is calculated automatically.
5. View the final score.
